# data/ (owner: Evan)

- `markets.csv`: the frozen market dataset. Columns:
  `market_id, source, category, question, created, resolved, snapshot_date, snapshot_price, outcome, volume`
  - `snapshot_price` is a probability from 0 to 1 (not a percentage).
  - `outcome` is 1 if the market resolved YES, 0 if NO.
- `same_event_drops.csv`: markets removed by the "one market per event" rule
  (same event with a different deadline, window or threshold, or a mutually
  exclusive outcome). Columns: `market_id, kept_market_id, reason`. Within each
  group the highest-volume market is kept. Applied by
  `python -m scripts.drop_same_event` (14 dropped from the 300 pulled; 286 remain).
- `decoys.csv`: generated by `python -m scripts.make_decoys`. Do not edit by hand.

Order after a fresh pull: write `markets.csv` and `split.csv`, run
`python -m scripts.drop_same_event`, then `python -m scripts.make_decoys`.
`tests/test_data.py` fails if any step was skipped.
- `split.csv`: dev/test assignment per market (Aryan and Evan). Columns:
  `market_id, split`, where split is `dev` or `test`.
- `DATA_CARD.md`: counts dropped by each filter, and final counts by category and platform.
